HABITFLOW — ZERO-BUILD SUPABASE PWA

Plain HTML/CSS/JS. No React, Node, npm, or build process.

Files:
- index.html
- style.css
- app.js
- config.js
- manifest.json
- sw.js
- icons/icon.svg

Features:
- Material 3-inspired minimal UI
- TickTick-style week selector
- Home + Stats
- Add / rename / delete habits
- Email/password authentication
- Supabase cloud storage
- Cross-device syncing
- Realtime subscriptions
- Offline/local UI cache
- PWA manifest + service worker

See SETUP.txt for the only configuration steps.
