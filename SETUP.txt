HABITFLOW SUPABASE SETUP

1. Put your Project URL and Publishable key into config.js.
2. In Supabase SQL Editor, run SUPABASE_MIGRATION_REORDER.sql ONCE.
3. Open the app through localhost or an HTTPS website.
4. Sign in with the same account on PC and phone.

REORDERING
- Desktop: drag a habit using the dotted handle.
- Phone: open the ⋯ menu on a habit and use Move up / Move down.
- The order is saved to Supabase, so the same order appears on your other devices.

IMPORTANT
Use only the Supabase Project URL and Publishable key in config.js. Never use the secret/service-role key.
