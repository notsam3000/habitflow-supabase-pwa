HABITFLOW + SUPABASE — SIMPLE SETUP

1. Open config.js in a text editor.

2. Replace:
   PASTE_YOUR_PROJECT_URL_HERE
   with your Supabase Project URL.

3. Replace:
   PASTE_YOUR_PUBLISHABLE_KEY_HERE
   with your Supabase Publishable key.

4. Save config.js.

5. Run the app through a local web server or deploy it to a normal HTTPS website.
   Do not rely on opening index.html with file:// for PWA/service-worker features.

6. Open the app on your PC and create an account.

7. On your phone, open the same deployed app and sign in with the same account.
   Your habits/checkmarks will be loaded from Supabase.

IMPORTANT:
- Use the Publishable key only.
- NEVER put the Supabase secret/service-role key in config.js.
- You already ran the database SQL from the earlier step.

If you want realtime updates while both devices are open, run this additional SQL
in Supabase SQL Editor:

alter publication supabase_realtime add table public.habits;
alter publication supabase_realtime add table public.habit_completions;

The app already subscribes to those changes.
